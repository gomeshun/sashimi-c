# Archived notebooks

These original notebooks record the pre-migration examples and intermediate
migration demonstrations. Their cells and saved results are retained for historical
context; they are not the supported entry point for the current release.

Use [the physical walkthrough](../usage_walkthrough.ipynb) for the ITAMAE-backed
API, explicit units, and current results. Use [scientific validation](../scientific_validation.ipynb)
for the migration comparison and its limitations. Reproducing an archived result
requires its original code and environment; see the independent reference workflow
in the SASHIMI-family repository.
